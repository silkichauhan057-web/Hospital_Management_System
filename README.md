# 🏥 Hospital Management System

A desktop-based management application built with **Java, JDBC, and MySQL** designed to streamline hospital administration, patient record tracking, doctor appointments, and medical database operations.

---

## 📌 Project Overview
Managing healthcare records manually often leads to data duplication and scheduling delays. This project provides a centralized, relational database solution that enables:
- Efficient patient admission and discharge record management.
- Doctor scheduling and appointment tracking.
- Secure, real-time database queries using JDBC connectivity.

---

## 🛠️ Tech Stack & Tools
- **Programming Language:** Java (Core Java, OOP Concepts)
- **Database:** MySQL / SQL
- **Connectivity:** JDBC (Java Database Connectivity)
- **IDE:** Eclipse / IntelliJ IDEA / VS Code

---

## ⚙️ Key Features
- **Patient Management:** Add, update, view, and delete patient records securely.
- **Doctor Allocation:** Check doctor availability and assign patients accordingly.
- **Appointment Booking:** Schedule appointments and prevent double-booking issues.
- **Database Persistence:** Real-time data storage and CRUD operations handled through SQL queries.
